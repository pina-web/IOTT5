Summary

이 제품을 한 줄로

지그비(Zigbee) IoT 디밍 T5 조명입니다. 스마트 리모컨, 스마트싱스 허브 앱, 블루투스(eWeLink 앱) 세 가지 방법으로 켜기/끄기 · 밝기 · 색온도(주광·주백·전구)를 조절할 수 있습니다.

제어 방법 3가지

허브가 있으면IoT 허브 + 조명삼성 스마트싱스 허브 권장. SmartThings 앱에서 기기 추가
허브가 없으면블루투스 연결eWeLink 앱 설치·가입 후 QR 스캔으로 추가
앱이 어려우면리모컨으로만리모컨 번호 1~4에 조명을 나눠 연결, 전체 ON/OFF 가능

상담 전 고객에게 확인할 것

  • IoT 허브가 있는지있다면 어떤 브랜드인지 (스마트싱스 권장)
  • 휴대폰 기종안드로이드 / 아이폰 (앱 설치 경로 안내용)
  • 조명 개수와 묶음리모컨 번호 1~4로 몇 그룹을 나눌지
  • 지금 증상연결 안 됨 / 일부만 반응 / 깜빡임 / 설정 초기화 필요

핵심 조작 4가지

리모컨 페어링조명 전원을 켜고 바로 원하는 번호(1~4)의 켜짐 또는 꺼짐을 3회 이상 연속 누름
리모컨 번호 초기화해당 번호의 켜짐 + 꺼짐을 동시에 5초 누름
조명 페어링 모드
· 제품 초기화		벽 스위치로 전원을 빠르게 5회 껐다 켜기 반복 → 조명이 깜빡이면 페어링 모드
메모리 기능다시 켜면 끌 때와 같은 밝기·색온도로 켜짐
Q & A

고객 문의별 응대

질문을 누르면 확인 포인트와 안내 멘트가 펼쳐집니다. 멘트는 복사해서 카톡·문자에 붙여 넣으세요.

리모컨리모컨으로 조명이 안 켜져요›
확인

리모컨과 조명이 아직 페어링되지 않았거나, 다른 번호에 연결되어 있을 수 있습니다. 전체 ON으로 반응하는지 먼저 확인합니다.

안내 멘트

고객님, 리모컨과 조명을 연결해 주셔야 합니다. 1) 벽 스위치로 조명을 켜 주세요. 2) 켜자마자 바로, 리모컨 아래쪽 1~4번 중 원하는 번호의 [켜짐] 또는 [꺼짐] 버튼을 3번 이상 연속으로 눌러 주세요. 연결되면 그 번호 버튼으로 해당 조명을 켜고 끌 수 있습니다.

리모컨조명 여러 개를 리모컨 하나로 쓰고 싶어요›
확인

번호는 1~4까지 4그룹입니다. 같은 번호에 여러 조명을 연결하면 함께 켜지고, 다른 번호에 연결하면 따로 제어됩니다.

안내 멘트

리모컨 하나로 여러 조명을 쓰실 수 있습니다. 조명마다 전원을 켜자마자 리모컨 번호 버튼(켜짐 또는 꺼짐)을 3번 이상 눌러 연결해 주세요. 예를 들어 거실은 1번, 주방은 2번으로 연결하시면 번호별로 따로 켜고 끌 수 있고, [전체 ON/OFF]로 한 번에 제어도 됩니다.

리모컨리모컨 번호를 다시 설정하고 싶어요›
확인

번호별로 초기화됩니다. 초기화 후 원하는 조명을 다시 페어링합니다.

안내 멘트

다시 설정하실 번호의 [켜짐]과 [꺼짐] 버튼을 동시에 5초간 눌러 주세요. 그 번호의 연결과 설정이 초기화됩니다. (예: 2번을 초기화하려면 2번 켜짐 + 2번 꺼짐을 동시에 5초) 그다음 조명 전원을 켜자마자 원하는 번호 버튼을 3번 이상 눌러 다시 연결해 주세요.

앱휴대폰으로 조절하고 싶어요 (허브 있음)›
확인

삼성 스마트싱스 허브 기준 절차입니다. 다른 브랜드 허브는 해당 허브 업체 설명서를 따르도록 안내합니다. 허브가 먼저 앱에 연결되어 있어야 합니다.

안내 멘트

SmartThings 앱에 허브가 연결된 상태에서 진행해 주세요. 1) 벽 스위치로 조명 전원을 빠르게 5번 껐다 켜 주세요. 조명이 깜빡이면 연결 준비가 된 상태입니다. 2) 앱 하단 [기기] 탭 → 오른쪽 위 [+] → 아래쪽 [주변 검색]을 눌러 주세요. 3) 조명이 검색되면 [완료]를 눌러 주세요. 검색에 시간이 조금 걸릴 수 있습니다. 4) 추가된 조명을 누르시면 밝기, 색온도, 켜기/끄기를 조절하실 수 있습니다.

앱허브가 없는데 휴대폰으로 쓸 수 있나요›
확인

블루투스로 eWeLink 앱에서 제어합니다. 회원가입(이메일 인증)이 필요하고, 설명서의 QR코드를 스캔해야 합니다.

안내 멘트

허브가 없으셔도 블루투스로 사용하실 수 있습니다. 1) 앱스토어에서 'eWeLink'를 설치하고 회원가입해 주세요. (국가: Korea, 이메일로 인증코드 수신 → 스팸함도 확인) 2) 앱 상단 [+] → [Scan]을 누르고, 설명서에 있는 QR코드를 비춰 기기를 추가해 주세요. 3) 추가된 기기를 누르신 뒤, 조명 전원을 켜는 동시에 화면의 [연결하기] 버튼을 빠르게 눌러 주세요.

앱앱에서 조명이 검색되지 않아요›
확인

조명이 페어링 모드가 아니면 검색되지 않습니다. 스마트싱스는 깜빡이는 상태에서 주변 검색을 해야 하고, eWeLink는 전원을 켜는 순간 연결하기를 눌러야 합니다.

안내 멘트

조명을 연결 준비 상태로 바꾼 뒤 다시 검색해 주세요. 벽 스위치로 전원을 빠르게 5번 껐다 켜시면 조명이 깜빡이면서 연결 준비 상태가 됩니다. 그 상태에서 앱의 검색(연결)을 다시 진행해 주세요. 검색에는 시간이 조금 걸릴 수 있습니다.

초기화설정을 처음 상태로 되돌리고 싶어요›
확인

조명 초기화와 리모컨 번호 초기화는 방법이 다릅니다. 어느 쪽인지 구분해서 안내합니다.

안내 멘트

· 조명 초기화: 벽 스위치로 전원을 빠르게 5번 껐다 켜기를 반복해 주세요. · 리모컨 번호 초기화: 해당 번호의 [켜짐]과 [꺼짐]을 동시에 5초간 눌러 주세요.

사용껐다 켜면 밝기·색이 바뀌나요›
안내 멘트

메모리 기능이 있어서, 다시 켜시면 끄실 때와 같은 밝기와 색으로 켜집니다.

번호 초기화

예시 2번 초기화 → 켜짐 2 + 꺼짐 2 동시에 5초

STEP 2앱에서 IoT 조명 연결

삼성 스마트싱스 허브가 호환성이 가장 좋습니다. 다른 브랜드 허브는 해당 허브 업체의 사용 설명서를 참고하도록 안내

  1. 앱·허브 연결 완료 후 조명을 페어링 모드로 전환 전원을 빠르게 5회 껐다 켜기 반복 → 깜빡이면 페어링 모드
  2. 앱 메인 하단 기기 탭 진입
  3. 오른쪽 상단 + → 하단 주변 검색
  4. 조명 검색 후 완료 검색에 시간이 걸릴 수 있음
  5. 조명을 누르면 색온도·밝기 조절, 온/오프 가능

① eWeLink 설치·가입

  1. 플레이스토어에서 ewelink 검색 후 설치 아이폰은 App Store에서 같은 이름으로 검색
  2. 앱 실행 → 사용자 등록
  3. 국가 Korea 선택, 인증코드 받을 이메일 입력
  4. 메일함(스팸함 포함)의 인증코드와 비밀번호 입력
  5. 가입한 이메일·비밀번호로 로그인

② 블루투스 제어 연결

  1. 앱 상단 + → Scan
  2. 설명서의 QR코드 스캔 → 디바이스 추가 이름 변경 가능
  3. 추가된 디바이스 선택
  4. 조명 전원을 켜는 동시에 연결하기를 빠르게 누르면 페어링 완료
